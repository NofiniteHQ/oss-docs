# Nofinite Locale

Nofinite Locale is a lightweight utility library that provides country metadata, international dialing codes, and CSS-based flags for web applications.

It is designed to work with modern JavaScript frameworks as well as plain HTML environments via CDN.

---

## Features

- Country metadata including name, ISO-2 code, and dial code
- Fully type-safe APIs for TypeScript
- SVG-based flags delivered through CSS
- Compatible with frameworks and no-build environments
