# Release Notes

## v1.0.0

**Release Date:** 2026-04-01

### Overview

Initial public release of the Nofinite Open Source documentation hub.

### What's Included

- Complete documentation structure for all Nofinite open-source libraries
- Guides, API references, and installation instructions for:
  - NUI
  - NUI CSS
  - Utils
  - Locale
  - Markon
- Responsive documentation website built with Docusaurus v3
- Automated deployment pipeline via Cloudflare Pages

### Technical Details

- **Framework:** Docusaurus 3.9.2
- **Node.js:** v20+
- **Package Manager:** pnpm
