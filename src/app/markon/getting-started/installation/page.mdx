# Installation

This page covers how to install `@nofinite/markon` in your project.

---

## Package Installation

Install the package using your preferred package manager.

### npm

```bash
npm install @nofinite/markon
```

### yarn

```bash
yarn add @nofinite/markon
```

### pnpm

```bash
pnpm add @nofinite/markon
```

---

## Requirements

- Node.js 16 or later (recommended)
- Works in both React and non-React environments

No additional peer dependencies are required.
